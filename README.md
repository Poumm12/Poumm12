## 🚀 Projects

### 🌾 AgroExchange — αγροτικό marketplace
*Ομαδικό project · Ρόλος: developer (υλοποίηση της εφαρμογής)*
**Live:** https://agroexchange1.vercel.app

Πλατφόρμα που συνδέει παραγωγούς, αγοραστές και μεταφορείς, με dashboard για αγγελίες, προσφορές, τιμές αγοράς, καιρό, μεταφορές και ειδήσεις.

- Integration με το EU Agri-Food Data Portal API για live τιμές αγοράς, με export σε CSV / Excel / PDF
- Πλατφόρμα μεταφορών με route requests, status tracking και reviews
- PostgreSQL schema με versioned migrations και Row Level Security

`Next.js 14` `TypeScript` `Supabase` `PostgreSQL` `Tailwind` `Vercel`
